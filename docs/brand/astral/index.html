What the brand
is grounded in.

The supplied README defines Astral Harness as prompt, skill, and evaluation assets supporting the backend-owned guide. This identity gives that work a prominent feature story without presenting integration as complete.

Documented scope

Selected-star context, comparison, constant-speed travel estimates, and approved community content are the guide’s subject areas. The backend owns the read-only tools and access boundaries.

Release boundary

Stage 1 prompt and skill files are not wired into the backend. Local tooling checks are not proof of shipped model performance. Campaign availability and capability claims need release verification.
