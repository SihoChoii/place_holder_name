Draft one note under 140 characters or one comment under 280 characters in the user's voice. Discover an authorized tag when needed, then call the appropriate propose tool. If no single visible post can be resolved, ask which post the user means; never guess a tag ID. Explain that the user must confirm in the app; drafts do not publish anything. A note requires ownership.
